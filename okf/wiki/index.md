## concepts

- [Compounding knowledge](concepts/compounding-knowledge.md): Knowledge that gets richer with each ingest and filed query instead of being rediscovered from scratch.
- [LLM Wiki](concepts/llm-wiki.md): Pattern where an LLM maintains a persistent interlinked markdown wiki between users and raw sources.
- [Open Knowledge Format](concepts/open-knowledge-format.md): Vendor-neutral markdown+YAML format for portable, agent-friendly knowledge bundles.
- [Structure learning](concepts/structure-learning.md): Inferring graph structure (often causal or probabilistic) from data; the core task Benchpress benchmarks.
