# OKF spec overview (source summary)

Local abridgement of Google’s Open Knowledge Format specification: knowledge as markdown+YAML, required `type`, reserved index/log files, and optional provenance/trust/lifecycle metadata in v0.2.

Concept page: [Open Knowledge Format](../concepts/open-knowledge-format.md).

## Key Takeaways

- Portable, git-friendly, agent-writable.
- No central type registry.
- Standard markdown links between concepts.
